# design

Figma'dan aldığınız ekran görüntülerini, export edilen görselleri veya tasarım dosyalarını buraya koyabilirsiniz.

Örnek düzen:
- `design/screens/` — her ekranın PNG/JPG görselleri
- `design/tokens/` — renk, yazı tipi gibi tasarım değişkenleri (varsa)

Bu klasördeki dosyalar uygulamanın çalışmasını etkilemez, sadece referans olarak durur.
